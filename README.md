# Rule-Based Expert System

A Rule-Based Expert System developed as part of the Syntecxhub Artificial Intelligence Internship – Task 1.

## Project Overview

This project implements a small rule engine using IF-THEN rules and a fact base. The system accepts facts or symptoms from the user and uses forward chaining to infer conclusions.

## Features

- Fact-based knowledge system
- IF-THEN rule engine
- User-provided facts
- Forward chaining
- Multi-step inference
- Inference step logging
- Final conclusions

## Technology Used

- Python

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder.
4. Run:

```bash
python expert_system.py
